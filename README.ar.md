لو بتقدّم على Chevening أو Fulbright أو DAAD أو Erasmus Mundus أو ماجستير برّه، فغالباً عندك كذا مقال، وميعاد تسليم واحد، ومفيش حد يقولك رأيه بصراحة. الإضافة دي بتخلّي Claude Code هو الشخص ده.

بتسألك مرة واحدة وتفتكر قصصك، وبتراجع مقالك زي لجنة قرت مية مقال النهارده. بتمسك التناقضات بين مقالاتك اللي مكنتش هتاخد بالك منها، وعارفة كل منحة بتختبر إيه وقاعدتها في الذكاء الاصطناعي، وبتعمل معاك إنترفيو تجريبي. اتكلم معاها بالمصري أو الخليجي أو الشامي أو المغاربي، وهي تكتب المقال بالإنجليزي.

مبنية على منهج مجرَّب لكتابة الـ personal statement، ومعاها الإرشادات الرسمية لـ ١٢ برنامج منح.

## التثبيت

</div>

```text
/plugin marketplace add MrFr0g-X/scholarship-coach
/plugin install personal-statement-coach@scholarship-coach
```

<div dir="rtl">

بعد كده اعمل Restart لـ Claude Code وافتحه في الفولدر اللي فيه ملفات التقديم.

**لو بتستخدم claude.ai:** نزّل ملف [`dist/personal-statement-coach.skill`](dist/personal-statement-coach.skill) وارفعه من Settings ثم Capabilities ثم Skills.

## بتعمل إيه

- **بتفتكرك.** قصصك وملف الحقائق (أرقامك وتواريخك) وطريقة كتابتك بيتحفظوا في فولدر `applicant/` على جهازك.
- **بتراجع زي اللجنة.** تقييم من ١٠ معايير، وأهم ٣ تعديلات، وملاحظات سطر بسطر بالقاعدة اللي اتكسرت.
- **بتمسك التناقضات.** لو نفس القصة اتكررت في مقالين، أو كتبت سنة في مقال وسنة تانية في مقال تاني، هتعرف فوراً.
- **عارفة كل منحة.** كل مقال بيختبر فيك إيه، وتوزيع الكلمات، واللينكات الرسمية.
- **عارفة قواعد الذكاء الاصطناعي.** Chevening ممنوع، Rhodes مسموح بحدود مع الإفصاح، DAAD مسموح لو ذكرته، وكامبريدج ممنوع حتى في تصحيح الإنجليزي. الأداة بتقولك القاعدة مرة واحدة.
- **بتمرّنك على الإنترفيو.** لجنة افتراضية بتسألك من مقالاتك إنت، وبتديك درجة على كل إجابة.
- **بتطلّع قصتك.** "أنا معملتش حاجة مميزة" بتتحوّل لزوايا قوية بتقنية الكورس: طريقة الحكي أهم من اللي عملته.
- **مبتألّفش.** أي معلومة ناقصة بتظهر كـ `[PLACEHOLDER]`، ومع كل مسودة قائمة بالحقائق اللي لازم تقدر تدافع عنها.

## البرامج وقواعد الذكاء الاصطناعي

Chevening · Rhodes · Gates Cambridge · DAAD · Fulbright · Erasmus Mundus · Commonwealth · MEXT · GKS · Türkiye Bursları · Stipendium Hungaricum · SOP للجامعات

كل ملف برنامج فيه مصادره الرسمية وتاريخ آخر مراجعة. المواعيد والحدود بتتغير كل سنة، فالأداة دايماً بتقولك تتأكد من الموقع الرسمي.

## الأمانة

- **مفيش معلومة متألّفة**، ولا حتى حاجة صغيرة زي لغتك الأم.
- **قاعدة منحتك بتتقال مرة واحدة**، والالتزام بيها قرارك.
- **مفيش حيل للتحايل على كواشف الذكاء الاصطناعي.** الهدف قصة حقيقية بصوتك.
- **بياناتك على جهازك.** فولدر `applicant/` مستبعد من git تلقائياً.
