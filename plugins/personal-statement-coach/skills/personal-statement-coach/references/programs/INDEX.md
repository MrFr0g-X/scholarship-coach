## AI-policy matrix (as last checked; always confirm on the live page)

| Program | Policy | What the skill does |
|---|---|---|
| **Chevening** | **Prohibited.** "Using artificial intelligence software to generate answers … is strictly prohibited." Detection tools are used; applicants attest at submission; breaches mean disqualification. | Say this once when drafting. Recommend Coach → Plan → the user writes → Review, or using drafts only as models the user rewrites. The user decides. |
| **Rhodes** | **Limited use with disclosure.** Generating substantive content is unacceptable. Shortening suggestions, spelling and grammar, summarising your own narrative and structuring help are acceptable. Disclose the tool **and the prompts**. | Coach, Plan, Review, Tighten (as suggestions), Polish and Interview prep fit within the policy. Write mode doesn't; say so once. Remind the user to keep a help log. |
| **Gates Cambridge / Cambridge applications** | **Prohibited for personal statements and CVs, including help with English.** Research proposals may use AI with acknowledgement. False AI-generated claims are treated as application fraud. | Say it once. Coach, Plan, Review as feedback, and interview practice only; the user writes and edits. |
| **DAAD** | **Allowed if declared.** Add "Produced with the aid of (tool used)" to the documents. | Draft or edit as asked; always remind the user to add the disclosure line. |
| Fulbright, Erasmus Mundus, GKS, MEXT, Türkiye Bursları, Commonwealth, Stipendium Hungaricum, other universities | No central policy found (varies by country, consortium or portal). | Tell the user to check the portal's declaration before using AI-drafted text. |

The honesty rules apply everywhere regardless of policy: **no invented facts, ever**, and every claim must be defensible in an interview.
